Smart Search Favorites & Bar v2.0.0 — Установка и новинки

Как установить:
1. Распакуйте этот ZIP-архив в удобную папку.
2. Откройте chrome://extensions/ (или edge://extensions/).
3. Включите «Режим разработчика» (Developer mode) в правом верхнем углу.
4. Нажмите «Загрузить распакованное расширение» (Load unpacked) и выберите распакованную папку.

Что нового в v2.0.0:
- Встроенная оффлайн-база тегов (Nyaa, Danbooru, ExHentai/E-Hentai, nhentai) + импорт внешних баз CSV/JSON в popup.
- Автодополнение по последнему слову в строке поиска; клик по тегу вставляет его, не отправляя форму.
- Заменены window.prompt() и confirm(): кнопка «+ тег» открывает инлайн-поле с живыми подсказками, а чипсы удаляются в 1 клик по ×.
- 3 состояния чипсов: ЛКМ (+тег), ПКМ (-тег исключение), повторный клик (убрать).
- Панель операторов мышкой (− Исключить, "" Точно, OR, фильтры female:/male:/artist:/parody:, кнопка «🔍 Найти»).
- Сбор тегов прямо со страниц (кнопка «+ тег» при наведении на теги галереи).
- СКМ (колёсико мыши) по фавориту/истории открывает поиск в новой вкладке.
