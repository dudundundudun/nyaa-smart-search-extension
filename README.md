# 🔍 Smart Search Favorites & Bar

**Умная панель поиска для браузера: база тегов, автодополнение по последнему слову и сборка запросов кликами мыши.**






&lt;/div&gt;

Расширение превращает обычную строку поиска на торрент-трекерах, буру-архивах и любых других сайтах в интерактивный конструктор тегов. Больше не нужно помнить точное написание длинных тегов или переключать раскладку ради кавычек и минусов — большинство действий делается **в один клик мышкой**.

## ✨ Ключевые возможности

- **📚 Встроенная база тегов + живое автодополнение** — подсказки ищутся по последнему набираемому слову, отсортированы по популярности и раскрашены по категориям (`artist`, `character`, `parody`, `female`, `male`, `meta`). Клик по подсказке вставляет тег в строку, не отправляя форму раньше времени.
- **🖱️ 3-состояния быстрых чипсов** — кликайте по закреплённым тегам, чтобы мгновенно собирать или фильтровать запрос без набора текста.
- **➕ Инлайн-добавление тегов** — кнопка `+ тег` открывает компактное поле прямо в шапке с живыми подсказками из базы (без блокирующих системных `prompt()`-окон).
- **⚡ Панель операторов и неймспейсов** — кнопки `− Исключить`, `"" Точно`, `OR`, быстрые фильтры (`female:`, `male:`, `artist:`, `parody:`, `character:`, `language:`) и кнопка `🔍 Найти`.
- **🏷️ Сбор тегов прямо со страниц** — при наведении на теги внутри галерей или постов появляется кнопка `+ тег`, позволяющая закинуть тег в быстрые чипсы или сразу в поиск.
- **🗂️ Изолированные профили и бэкапы** — для каждого сайта хранится своя база чипсов, избранного (с drag-and-drop сортировкой) и истории запросов, с экспортом/импортом в `.json`.
- **📥 Импорт сторонних словарей** — через popup можно загрузить готовые базы на десятки тысяч тегов (`.csv` от Danbooru/e621 или `.json` от EhTagTranslation).

## 🌐 Поддерживаемые сайты и стартовые профили

Расширение работает на любом сайте (при необходимости поле поиска указывается вручную кнопкой **«🎯 Указать строку поиска кликом»**), а для популярных площадок уже настроены готовые пресеты:

| Площадка | Что включено из коробки |
| :--- | :--- |
| **Nyaa** (`nyaa.si`, `nyaa.land`, `sukebei.nyaa.si`) | Релиз-группы (`[SubsPlease]`, `[Erai-raws]`, `[EMBER]`), разрешения, кодеки, автоподстановка категорий |
| **nhentai** (`nhentai.net`) | Популярные языковые и жанровые чипсы (`russian`, `english`, `translated`, `full color`, `uncensored`, `-yaoi`) |
| **ExHentai / E-Hentai** (`exhentai.org`, `e-hentai.org`) | Префиксы `language:`, `female:`, `male:`, `artist:`, `parody:` и автоформатирование тегов с пробелами |
| **Danbooru / Gelbooru** (`danbooru.donmai.us`, `gelbooru.com`) | Базовые мета-теги (`1girl`, `solo`, `highres`, `absurdres`, `order:score`, `rating:*`) |

## 🖱️ Шпаргалка по управлению мышкой

| Действие | Результат |
| :--- | :--- |
| **ЛКМ** по чипсу | Добавить тег в строку поиска / убрать его |
| **ПКМ** по чипсу | Добавить или убрать **исключение** (`-тег`) |
| Наведение на чипс → **×** | Удалить чипс из панели в 1 клик |
| **ЛКМ** по подсказке из базы | Вставить тег в текущее слово (меню остаётся открытым) |
| **СКМ (колёсико)** по фавориту/истории | Открыть результаты поиска в новой вкладке |
| Кнопки **⌫** / **×** внутри строки | Удалить последний тег целиком или очистить всю строку |
| **Наведение на тег на странице** → **+ тег** | Добавить в чипсы (`Shift + клик` — сразу в строку поиска) |

## 🚀 Установка

1. Скачайте архив с релизом (или клонируйте репозиторий) и распакуйте его в любую папку.
2. Откройте в браузере страницу расширений: `chrome://extensions/` (для Chrome) или `edge://extensions/` (для Edge).
3. Включите **Режим разработчика** (*Developer mode*) в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** (*Load unpacked*) и выберите папку проекта.

## 📦 Подключение больших баз тегов (опционально)

По умолчанию в расширение вшита компактная база самых популярных тегов. Чтобы получить автодополнение по десяткам тысяч тегов:

1. Скачайте готовый словарь:
   - для **Danbooru / e621** — CSV-списки из [a1111-sd-webui-tagcomplete](https://github.com/DominikDoom/a1111-sd-webui-tagcomplete) или [dbr-e621-lists-archive](https://github.com/DraconicDragon/dbr-e621-lists-archive);
   - для **E-Hentai / ExHentai** — файл `db.html.json` из релизов [EhTagTranslation/Database](https://github.com/ehtagtranslation/Database/releases).
2. Нажмите на иконку расширения в браузере и кликните **«⬆ Загрузить теги»**.
