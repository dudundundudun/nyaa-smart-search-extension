# 🎯 Smart Search Favorites & Bar (v3.0 World-Class Mouse Edition)

Умная панель поиска для браузеров Chrome / Edge / Brave (Manifest V3), созданная специально для **100% управления одной мышкой без клавиатуры** на сайтах **Nyaa**, **ExHentai / E-Hentai**, **nhentai**, **Danbooru**, **Gelbooru** и любых других трекерах и галереях.

## ✨ Что нового в версии v3.0

* **💊 Интерактивные капсулы текущего запроса («Сейчас в поиске»):** Каждое слово или тег в строке поиска отображается отдельной кнопкой-капсулой.
  * **ЛКМ** по капсуле — удалить слово даже из середины длинного запроса.
  * **ПКМ** по капсуле — поставить или убрать минус (`-тег` для исключения).
  * **СКМ (колёсико)** по капсуле — взять в точные кавычки `""`.
* **🔥 Самообучающиеся топ-чипсы:** Расширение анализирует вашу историю и избранное на каждом сайте и автоматически выводит ваши самые частые теги со значком `🔥` в верхний ряд.
* **🗂 Вкладки категорий тегов в 1 клик мышкой:** Удобное переключение рубрик (`🔥 Топ`, `🌐 Язык и цвет`, `♀ Девушки`, `💗 Жанры и фетиши`, `♂ Мужчины`, `🎨 Пародии / Тайтлы`, `🎬 Релиз-группы`, `📺 Качество / Кодек`) с мгновенным добавлением следующих тегов.
* **🇷🇺 Русский перевод прямо на кнопках:** Встроенная база расширена до 215+ самых популярных тегов с понятным русским переводом (можно включать/выключать в меню расширения).
* **⚡ Быстрые фильтры сайтов прямо в панели:**
  * **Nyaa:** переключение рубрик (`Anime Eng`, `Anime Raw`, `Manga`) и фильтров (`No Remakes`, `Trusted`) в 1 клик.
  * **ExHentai / nhentai:** кнопки `★ 4+`, `★ 5`, `📖 20+ стр.`, `📖 50+ стр.`, `📚 100+ стр.`, `🚫 Без AI`, `🚫 Без Яоя`.
  * **Danbooru / Gelbooru:** кнопки `🔥 По рейтингу`, `🟢 SFW`, `🔞 NSFW`, `🚫 Без видео`.
* **🚀 Нулевая нагрузка на браузер:** Скрипт полностью отключает слушатели событий на обычных сайтах и лениво подгружает базу тегов без лишнего расхода памяти.

## 🛠 Установка / Обновление

1. Распакуйте архив `nyaa-smart-search-extension-v3.0.zip` в постоянную папку.
2. Откройте `chrome://extensions/` и включите **«Режим разработчика»** (Developer mode).
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку (или нажмите 🔄 **«Обновить»**, если прошлая версия уже установлена).
4. Обновите открытую вкладку сайта (`F5`).
