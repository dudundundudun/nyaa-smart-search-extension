# 🔍 Smart Search Bar & Favorites (nyaa.si Edition)






Умное расширение для **Google Chrome / Brave / Edge**, которое превращает обычную строку поиска на `nyaa.si` (и любых других выбранных вами сайтах) в удобную панель быстрого поиска в тёмном стиле `nhentai.net`. Создано для того, чтобы искать онгоинги, релиз-группы и батчи **одной мышкой — вообще без клавиатуры**.

## ✨ Основные возможности

### 1. Кнопки быстрой очистки прямо внутри строки поиска (`×` и `⌫`)
Когда в строке поиска есть текст, справа внутри неё появляются две компактные кнопки:
- **`×` (Очистить всё)** — в один клик стирает весь запрос, оставляет фокус в поле и сразу раскрывает ваше меню фаворитов. Больше не нужно тянуться к `Backspace` или выделять старый текст мышкой.
- **`⌫` (Стереть последнее слово или тег)** — удаляет только последний тег (например, `1080p` или `[SubsPlease]`), оставляя само название тайтла нетронутым.

### 2. Выпадающее меню с редактируемыми фаворитами (`★ Saved`) и историей (`🕒 Recent`)
При клике на строку поиска открывается тёмное табличное меню (изолированное через `Shadow DOM`, поэтому вёрстка сайта его никогда не сломает):
- **Закреплённые фавориты (`★`) всегда сверху** — по умолчанию первой строкой уже добавлен пресет `[SubsPlease] 1080p`.
- **Два режима клика по строке**:
  - Клик **по самой строке** — сразу подставляет запрос и запускает поиск.
  - Клик **по стрелке `→` справа** — мягко дописывает запрос или тег в строку поиска с пробелом, чтобы вы могли скомбинировать несколько элементов.
- **Редактирование и сортировка на месте**: любую запись в избранном можно переименовать кнопкой `✎`, перетащить мышкой за иконку `⠿` выше/ниже или удалить кнопкой `×`.
- **Умная история и счётчик (`🕒`)**: расширение само считает, сколько раз вы искали каждый запрос (например, `8×`), и выводит топ частых поисков под фаворитами. Любой удачный запрос из истории можно в один клик поднять в избранное кнопкой `☆`.

### 3. Панель быстрых чипсов-тегов в один клик
В самой шапке выпадающего списка расположены кнопки популярных фильтров:
`[SubsPlease]`, `1080p`, `HEVC`, `Batch`, `10bit`, `[Erai-raws]`, `Dual Audio`, `-chinese`.
- **Левый клик по чипсу** — добавляет тег к текущему запросу в строке (повторный клик — убирает его из строки).
- **Кнопка `+ тег`** — позволяет добавить свой собственный чипс прямо из меню.
- **Правый клик по чипсу** — удаляет ненужный чипс с панели.

### 4. Пополнение фаворитов со страницы и работа по белому списку
- **Контекстное меню (Правый клик мышкой)**: выделите название любого аниме прямо в таблице раздач → нажмите правую кнопку мыши → выберите **«★ Добавить в фавориты поиска»** (или сразу **«★ Добавить "[SubsPlease] ... 1080p" в фавориты»**).
- **Включение только на нужных сайтах**: по умолчанию расширение активно на `nyaa.si`, `nyaa.land`, `sukebei.nyaa.si` и `nhentai.net`, а на всех остальных сайтах полностью спит. Включить или выключить его для любого домена можно тумблером в окне расширения (если у сайта нестандартная вёрстка, кнопка **«🎯 Указать строку поиска кликом»** привяжет меню к любому полю).
- **Надёжное локальное хранение + Бэкап (`.json`)**: вся база хранится на диске через `chrome.storage.local` (`unlimitedStorage`) — она не пропадает после перезагрузки ПК или очистки кэша/куки браузера, а в окне расширения есть кнопки **Экспорт** и **Импорт** всей базы в файл `.json`.

## 🚀 Установка (за 1 минуту)

1. Скачайте этот репозиторий (зелёная кнопка **Code** → **Download ZIP**) и распакуйте архив в любую постоянную папку на компьютере (или склонируйте через `git clone`).
2. Откройте в браузере страницу управления расширениями:
   - Для Chrome: `chrome://extensions/`
   - Для Brave: `brave://extensions/`
   - Для Edge: `edge://extensions/`
3. Включите переключатель **Режим разработчика** (*Developer mode*) в правом верхнем углу.
4. Нажмите кнопку **Загрузить распакованное расширение** (*Load unpacked*) слева вверху и укажите папку с файлами расширения.

## 🎮 Как пользоваться на практике

| Действие | Что нажать | Результат |
| :--- | :--- | :--- |
| **Быстро очистить поиск** | Кнопка `×` внутри поля поиска | Стирает весь текст и сразу раскрывает список фаворитов |
| **Заменить только тег в конце** | Кнопка `⌫` внутри поля поиска | Стирает последнее слово/группу (например, меняет `1080p` на `Batch`) |
| **Запустить готовый поиск** | Левый клик по строке в списке | Подставляет запрос и автоматически нажимает поиск |
| **Собрать запрос из частей** | Клик по стрелке `→` или по чипсам сверху | Дописывает тег/название в строку без перезагрузки страницы |
| **Сохранить то, что ввели руками** | Звёздочка `☆` справа от строки `↵ Search for ...` | Закрепляет текущий текст из поля поиска в блок `★ Saved` |
| **Добавить тайтл со страницы** | Выделить текст → Правый клик мышкой | Сохраняет выделенное название прямиком в ваши фавориты |
